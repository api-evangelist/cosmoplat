# COSMOPlat (卡奥斯 COSMOPlat)

> Industrial internet platform incubated by Haier Group and operated by COSMOPlat Digital
> Technology (Qingdao) Co., Ltd. Its developer-facing surface is the 物联开发平台 (IoT
> development platform): a JSON API for products, devices, alarm rules, alarm records, rule
> chains, thing-model telemetry points, time-series telemetry and device RPC, plus an MQTT
> publish/subscribe telemetry surface.

This file is generated by API Evangelist from the COSMOPlat profile at
https://github.com/api-evangelist/cosmoplat. COSMOPlat does not publish an llms.txt.

Important for a machine reading this API: COSMOPlat publishes its API contract as an HTML
reference table only. It serves no OpenAPI, Swagger, Postman collection, AsyncAPI or
/.well-known/ document on any host. It publishes no base URL and no authentication scheme
for the REST operations, so the contract is readable but not callable without contacting
the platform administrator. The machine-readable documents linked below were transcribed
from the provider's published reference by API Evangelist and are labelled as such in their
own `x-provenance` blocks.

## APIs
